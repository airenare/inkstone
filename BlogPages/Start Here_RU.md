# Запуск

Чтобы опубликовать своё хранилище Obsidian в интернете, выберите подходящий вариант.

------------------------------------------------------------------------

## Вариант A — Запуск локально

**Требования:** Python 3.11+, Git

``` bash
git clone https://github.com/airenare/onyxfolio
cd onyxfolio
pip3 install -r requirements.txt
python3 app.py
# → http://127.0.0.1:8000
```

Чтобы использовать собственное хранилище вместо демо:

``` bash
echo "VAULT_PATH=/path/to/your/obsidian/vault" > .env
python3 app.py
```

Сервер отслеживает изменения файлов и автоматически перезагружается —
перезапуск не требуется.

------------------------------------------------------------------------

## Вариант B — Docker

``` bash
git clone https://github.com/airenare/onyxfolio
cd onyxfolio
docker build -t onyxfolio .
docker run -p 8000:8000 -v /path/to/your/vault:/vault onyxfolio
# → http://127.0.0.1:8000
```

Если `/vault` не подключён, будет загружено встроенное демо-хранилище.

------------------------------------------------------------------------

## Как опубликовать заметку

Добавьте `website: true` в frontmatter любой заметки:

``` yaml
---
website: true
title: My First Post
date: 2026-01-15
---

Напишите здесь всё, что хотите.
```

Теперь эта заметка опубликована, её URL — `/my-first-post`, если она
находится в корне хранилища, или `/section/my-first-post`, если она
лежит в подпапке.

------------------------------------------------------------------------

## Базовая структура хранилища


| Путь в хранилище                 | URL             |
| -------------------------------- | --------------- |
| `Home.md` (`type: homepage`)     | `/`             |
| `blog/Blog.md` (`type: listing`) | `/blog`         |
| `blog/My Post.md`                | `/blog/my-post` |
| `About.md`                       | `/about`        |
